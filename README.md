# api-with-spring-boot-and-java

# Sobre o projeto

Projeto feito afim de aprimorar as competências em Spring Boot, Swagger, JWT, Mockito, React JS e aprender sobre HATEOAS.

A aplicação consiste em uma API RESTFul de CRUD de Pessoas e Livros.

# Tecnologias utilizadas
## Back end
- Java
- Spring Boot
- JPA
- Postman
- Swagger
- JWT
- Mockito
- JUnit
- ReactJS

## Banco de Dados
- MySQL
